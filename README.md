# Eco-Sports
Plataforma web que incentiva el reciclaje otorgando 'Eco-Puntos' canjeables por artículos deportivos. Proyecto desarrollado para la ruta Jóvenes Creativos.

**Tecnologías usadas:**
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express, MongoDB (Local)
- IA: Integración con Gemini API para el Eco-Bot asistente
